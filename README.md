# 机型伪装

## 使用条件

- Android 8.0 或更新版本，已取得 Root 权限。
- Magisk、KernelSU 或 APatch 支持安装模块，并提供 `resetprop`。
- 使用兼容 libxposed API 102 的 LSPosed 框架，并启用“机型伪装”。应用启动时会检查 Root、模块和 LSPosed 状态。

## 安装

1. 在 Root 管理器中安装模块 ZIP，重启手机。
2. 模块会尝试自动安装配套应用；若安装失败，手动安装配套 APK。
3. 打开“机型伪装”，在 Root 管理器的提示中允许授权。
4. 在 LSPosed 中启用“机型伪装”，只勾选需要伪装的目标应用，无需勾选“机型伪装”自身。
5. 重启手机，重新打开“机型伪装”，确认启动检查通过。

升级时安装新版模块和配套应用后重启。覆盖安装 APK 需要使用相同签名。

## 配置机型

1. 在“配置”页选择手机或平板预设。
2. 按需开启“仅修改型号”“伪装 SoC 名称”或“伪装屏幕信息”。
3. 点击应用并确认，重启手机后全局机型属性生效。
4. 修改处理器或屏幕设置后，完整停止并重新打开目标应用；必要时重启手机。

“仅修改型号”只调整型号和市场名称；关闭时同时调整品牌和制造商。处理器和屏幕信息伪装需要目标应用在 LSPosed 作用域内。

## 外观设置

在“设置”页选择主题、颜色、主辅色拼色和动画速度，修改后自动保存。

## 恢复与卸载

- 恢复机型：点击“恢复原机型”并确认，然后重启手机。
- 关闭应用内伪装：关闭对应开关或取消目标应用的 LSPosed 作用域，完整停止并重开目标应用。
- 卸载：先恢复原机型并重启，再从 Root 管理器卸载模块，手动卸载配套应用。
- 启动异常：通过 Root 管理器的安全模式禁用模块后重启。

卸载模块会保留 `/data/adb/device_mask` 中的配置，重新安装可能读取旧配置。

## 使用注意

- 不要为 Android 系统、系统界面、设置、桌面或 Root 管理器开启伪装。
- 屏幕伪装可能影响目标应用布局，出现异常时关闭开关并重启目标应用。
- 伪装不会改变真实硬件；微信平板登录等应用识别结果需在实际设备上确认。
- 同时使用多个机型伪装模块可能影响原始属性记录，首次使用前先关闭其他同类模块。
